# GymBro

A full-stack AI-powered fitness tracking application built as a Telegram Mini App. Track workouts, manage routines, log sessions, analyse progress, and get personalised coaching from AI agents.

## Features

- **Routine Management** — Create, edit, reorder, and delete training routines with planned sets/reps/weight.
- **Live Session Tracking** — Start a workout, log each set in real time (reps, weight, RPE), mark sets as skipped, complete or cancel.
- **AI Training Splits** — Answer a short questionnaire and get a multi-day split generated by an AI agent using exercises from your library.
- **AI Coach (Rex)** — Chat with a fitness coach that queries your workout history, rates your routines, and gives data-driven advice.
- **AI Review** — Get a structured training report covering volume, muscle balance, PRs, session efficiency, and body metrics.
- **Progress Analytics** — Charts for workout frequency, muscle volume distribution, exercise PRs, body weight trends, and a workout calendar.
- **Exercise Library** — Browse 800+ global exercises filtered by muscle group or equipment, or create your own custom exercises.
- **Body Metrics** — Log weight and body fat percentage over time with trend visualisation.
- **Telegram Mini App** — Mobile-first UI that runs inside Telegram via a bot.
- **Redis Caching** — Exercise queries are cached for fast lookups.

## Architecture

```
Telegram
  |
  v
Bot (/start) ──> upserts user ──> PostgreSQL
  |
  v
Mini App (frontend/)
  |
  v
FastAPI (/api/v1/...)
  |
  ├── CRUD endpoints (users, exercises, routines, sessions, progress)
  ├── AI Agent endpoints (chat, review, create-routine)
  ├── Redis cache (exercise queries)
  └── PostgreSQL (all persistent data)
```

The FastAPI server serves both the REST API at `/api/v1/` and the frontend static files at `/ui/`.

## Installation

```bash

git clone <repo-url>
cd GYM_BRO

# Create virtual environment
python -m venv .venv

# Activate
# Windows
.venv\Scripts\activate
# Linux/Mac
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Configuration

Create a `.env` file in the project root:

```env
BOT_TOKEN=<your-telegram-bot-token>
DATABASE_URL=postgresql+asyncpg://postgres:<password>@localhost:5432/gymbro
GOOGLE_API_KEY=<your-google-api-key>
REDIS_URL=redis://localhost:6379
```

| Variable | Description |
|----------|-------------|
| `BOT_TOKEN` | Telegram bot token from BotFather |
| `DATABASE_URL` | PostgreSQL async connection string |
| `GOOGLE_API_KEY` | Google Generative AI API key for Gemini models |
| `REDIS_URL` | Redis connection URL (defaults to `redis://localhost:6379`) |

## Running the App

```bash
# 1. Run database migrations
alembic upgrade head

# 2. Start the backend (auto-reloads on file changes)
uvicorn app.main:app --reload

# 3. In a separate terminal, start the Telegram bot
python -m app.services.bot.bot
```

The API is available at `http://localhost:8000/api/v1/` and the frontend at `http://localhost:8000/ui/`.

For Telegram Mini App development, expose localhost via ngrok:

```bash
ngrok http 8000
```

Then update the bot's WebApp URL with the ngrok HTTPS URL.

## Database Models

### User
Telegram user profile. Primary key is the Telegram user ID.

### Exercise
Global or custom exercise with name, force type (push/pull/static), difficulty level, target muscles, and equipment type.

### Routine
Named collection of exercises with planned sets, reps, and weight for each.

### RoutineExercise
Join table linking routines to exercises, with ordering and planned programming.

### WorkoutSession
A single workout instance. Tracks status (in progress / completed / cancelled), date, duration, and optional notes.

### SessionLog
One logged set within a session. Records exercise, set number, set type (warmup/working/dropset), planned vs. actual reps and weight, RPE, and skip status.

### UserBodyMetric
Body weight and body fat percentage entries tracked over time.

### Enums
- **Force**: pull, push, static
- **Level**: beginner, intermediate, expert
- **MuscleGroup**: abs, legs, arms, shoulders, chest, back
- **Equipment**: barbell, dumbbell, kettlebells, machine, bands, cable, body_only, foam_roll, medicine_ball, exercise_ball, ez_curl_bar, other
- **SessionStatus**: in_progress, completed, cancelled
- **SetType**: warmup, working, dropset

## AI Agents

GymBro uses three specialised Google ADK agents powered by Gemini:

### Rex (Chat Agent)
An AI fitness coach that maintains conversation history per user. Rex can query the user's workout data via SQL, rate routines, analyse trends, and give personalised advice.

- **Endpoint**: `POST /agent/chat`
- **Input**: `{ "user_id": int, "message": str }`
- **Output**: `{ "reply": str }`

### GymAnalyst (Review Agent)
Generates a structured training report by querying session logs, volume data, PRs, body metrics, and routine details. No conversation memory — each call is independent.

Report sections: Stats Overview, Body Metrics, Muscle Balance, PR Board, Routine Ratings, Session Efficiency, Overall Summary.

- **Endpoint**: `POST /agent/review`
- **Input**: `{ "user_id": int, "days": int }`
- **Output**: `{ "report": str }`

### GymExpert (Create Agent)
Designs a multi-day training split from a user questionnaire. Uses the exercise library from the database to ensure all recommended exercises exist. Returns structured JSON with one routine per training day.

The number of days matches the user's stated availability (e.g., 3 days = Push/Pull/Legs, 4 days = Upper A/Lower A/Upper B/Lower B).

- **Endpoint**: `POST /agent/create-routine`
- **Input**: `{ "user_id": int, "answers": { ... } }`
- **Output**: `{ "routine": { "days": [ { "day": 1, "focus": "Push", "exercises": [...] } ] } }`

**Onboarding questions**: primary goal, age, height, weight, training availability, recovery & sleep, injuries, training background, training preference.

## Frontend

The frontend is a single-page application served as static files at `/ui/`. It is designed as a mobile-first Telegram Mini App.

### Pages

| Page | Description |
|------|-------------|
| **Home** | Dashboard with latest session and quick links |
| **Routines** | Create, view, and manage routines. AI-powered split generator wizard |
| **Session** | Live workout logging — pick a routine, log sets, track duration |
| **Progress** | Charts for frequency, muscle volume, exercise PRs, body weight, and workout calendar |
| **Exercises** | Browse and filter the exercise library, create custom exercises |
| **Chat** | Talk to Rex, the AI fitness coach |

### AI Wizard Flow
1. User taps "Create with AI" on the Routines page
2. Steps through 9 questions (goals, age, height, weight, availability, recovery, injuries, background, preference)
3. Agent generates a multi-day split
4. User previews the split grouped by day
5. User names the split and saves — one routine is created per day

## Telegram Bot

The bot handles the `/start` command, creates the user in the database, and presents an inline button that opens the Mini App inside Telegram.

```
User sends /start
  -> Bot upserts user via POST /users
  -> Bot replies with "Open GymBro" button (WebApp URL)
  -> User taps button -> Mini App opens in Telegram
```
